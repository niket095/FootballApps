# FootballApps

This app is designed to simplify the selection of teams when playing FIFA together with friends. It allows you to randomly select teams from a list of the strongest clubs, as well as keep track of the results of games in the standings. And also follow the real English Premier League standings in real time.

### Main functions:
Welcome screen:
- Greets the user when launching the application.

Command screen:
- Displays teams rated 4, 4.5, and 5 stars in strength from the FIFA soccer simulator.
- The "Randomizer" button: when pressed, a whistle will sound, and the team logos will start spinning with an animation of the team logo zooming in when stopping in the center.
- Refresh button: When pressed, the sound of hitting the ball will sound, and for a split second the labels will become invisible, after which the teams will appear in random order.

The Account screen:
- A table opens where you can enter the scores when playing together with a friend, making up the standings.

The "Table" screen:
- Displays the English Premier League standings in real time using WebView to download data from the website sports.ru .

### The project uses:
- Programming Language: Swift
- UI: UIKit + Code layout (without using Storyboard)
- webView: https://www.sports.ru/football/tournament/premier-league/table/
- Supported iOS Versions: iOS 13+
